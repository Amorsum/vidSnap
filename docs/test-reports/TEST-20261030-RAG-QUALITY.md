# N3 关键词检索降级验证

日期：2026-10-30。按用户要求先跳过数据库配置，选择不依赖数据库的 N3 检索质量工作；N1 的存储原型仍未接入应用。

## 范围与预期

- 日语假名、韩文词语、单个数字及英文查询应找到含相同线索的原文段落；全角字母数字与半角可互相匹配。
- 数字 `7` 不应匹配 `17`；中日韩字符不能跨标点拼接成原查询中不存在的词。
- 空查询或不包含匹配线索的查询不返回结果，命中保留原段落及时间。

## 结果

- [合成样本](../../tests/rag-quality.test.ts) 修复前复现日语假名无命中及标点跨词误命中；修复后四组检查通过。
- 已纳入 `npm run test:security`；本轮 271 项 TypeScript 与 49 项 Python 回归、lint 和 TypeScript 检查通过。隔离生产构建及三组共 25 项浏览器检查通过。
- 备份旧构建后完成本机生产构建与服务重启，保留现有隧道；本机首页及静态资源、公网首页均返回 HTTP 200。未执行真实视频或模型追问，HTTP 200 不证明这些链路正常。
- 此检查不调用模型、数据库或视频平台。它不评估自动转写误差、语义召回、否定语义、真实引用精度、复习题或回答质量；关键词命中不等于支持回答。
- 日语和韩文按连续字符生成二元组，短助词仍可能产生噪声；仍需真实样本和人工核查，不应把结果当作多语言质量通过。
