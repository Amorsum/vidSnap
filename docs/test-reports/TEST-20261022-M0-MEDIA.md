# M0 第六批：真实媒体小样本验收

日期：2026-10-22。开发分支：`demo`。前五批已推送，最新提交 `67414d1`；本批已在概述后获用户确认，纳入本次提交。

## 用例与预期

| 用例 | 预期 |
| --- | --- |
| 固定样本元信息 | ID 一致、非直播、时长在 0—30 秒；否则不下载 |
| 英文手动字幕 | 下载 VTT，生产解析器返回非空片段且时间范围与样本一致 |
| 真实音频 | 只选择已知大小、8 MiB 以内的单一 HTTPS 音轨；实际文件非空，FFprobe 音轨与时长有效 |
| 缺少字幕或合规音轨 | skip，不能报告媒体全部通过 |
| 元信息/字幕/音频/探测错误 | 分项失败，字幕失败不阻止音频检查，已有产物仍清理 |
| 日志隐私 | 不输出原始元信息、签名 URL、Cookie、字幕、私有路径或异常正文 |
| 回归/静态检查/构建 | 原有测试与新增测试通过；不干扰正在使用根目录 .next 的生产服务 |

## 真实执行

命令：`npm run --silent check:media -- --proxy http://127.0.0.1:7890 --json`。使用当前 Node/Python/yt-dlp/FFprobe，全部媒体请求通过现有受控 DNS/固定 IP/域名边界，不使用 Cookie，不调用付费模型。

| 检查 | 实际结果 |
| --- | --- |
| 元信息 | pass，固定公开样本 jNQXAC9IVRw，19 秒 |
| 字幕下载与生产解析 | pass，英文 VTT 440 字节，6 段，时间范围有效 |
| 音频下载与 FFprobe | pass，WebM 112596 字节，19.021 秒，存在音轨 |
| 本次产物清理 | pass |
| 报告 | media_sample_verified=true，full_pipeline_verified=false，退出码 0 |
| 一次诊断总耗时 | 20034 毫秒，含多次独立解析，不作为生产性能数据 |

开发前另一次受控探测也成功：下载 252182 字节音频和 440 字节字幕；两次音频体积不同源于格式选择，最终脚本选择符合门槛的最小音轨。此前只取得平台页面 HTTP 200；本批新增的解析/字幕/音频结果不能回填为此前已经验收。
