## 构建与浏览器

- `npx tsc --noEmit`、`npm run lint`：通过。
- 原字体原样隔离构建：即使临时提供代理，仍有 Geist Mono 的 Google Fonts 连接失败。该失败确实阻断构建，不记为通过。
- 改为真实本地字体后的隔离 `npm run build`：**通过**。没有 `NEXT_FONT_GOOGLE_MOCKED_RESPONSES`，没有构建代理；编译、类型检查、10 个静态项和 6 个 API 路由完成。
- 字体文件来自已有已验证部署的 Google Fonts 字节，11 个子集共 146464 字节，逐项 SHA-256 固定；没有升级/重编码字体。保留 Geist/Geist Mono 的全部 Unicode 范围、100—900 字重、swap、Arial fallback 度量和原 CSS 变量。附 [字体说明与许可](../../src/app/fonts/README.md)。
- Python Playwright + Chrome：1440×1000、390×844；两端均实际加载并解码 5 个 Geist 与 6 个 Geist Mono 子集，外部 Google Fonts 请求 0。
- 两端门禁错误/成功、存码刷新、HttpOnly 会话、输入/SSE 总结、3 张帧解码、追问、跨会话拒绝与删除通过；无横向溢出，pageerror=0。媒体/模型均为隔离服务测试替身。
- 测试仅使用 `127.0.0.1:3418` 的显式 mock 服务，结束后已停止；未重启 3000/3001 用户服务，未修改其 `.next`、隧道或环境。
