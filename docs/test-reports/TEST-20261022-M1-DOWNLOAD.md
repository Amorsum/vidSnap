# M1 第二批：字幕交接与实际媒体路径

日期：2026-10-22。分支 demo，最近已推送提交仍为 `8d11f93`；M1 第一批和本批已获用户确认，纳入本次提交。

## 预期与用例

| 用例 | 预期 |
| --- | --- |
| 元信息到字幕交接 | 同次解析最多交接一个人工和一个自动轨道；直接命中时不再次提取平台元信息、不下载音频 |
| 原语言与翻译轨道 | 优先元信息原语言、原始自动轨道；显式 tlang 翻译、非法语言/URL/格式不参与选择 |
| 交接边界 | 对象身份、URL、2 分钟期限、32 条容量及单次消费有效；公开元信息不含签名 URL |
| 空/损坏/失败字幕 | 清理无效文件，尝试备用轨道、一次 Cookie 下载器兜底，最终可下载音频转写，不误报无语音 |
| 删除竞态 | 当前分析被撤销后停止后续轨道/音频工作，不回写结果 |
| 实际媒体路径 | 接受报告的 M4A/WebM 等实际文件，拒绝多路径、目录外、不同视频、部分文件、空文件和同名目录 |
| 媒体出站 | YouTube 字幕沿用全量 DNS/固定 IP 和逐跳白名单；4 MiB/20 秒检查预算；失败清理部分文件 |
| 真实媒体小样本 | 生产处理器取得有效字幕；额外音频验证报告路径，独立 Cookie/临时目录收尾，不调用模型 |

## 真实运行

命令：`npm run --silent check:pipeline -- --workspace .\tmp\m0-session-validation --proxy http://127.0.0.1:7890 --media-only --json`。使用当前真实 yt-dlp、Python 出站边界和实际项目 Cookie 的独立副本；未替换上游、未监听 HTTP、未调用模型。

| 项目 | 实际结果 |
| --- | --- |
| 固定样本 | jNQXAC9IVRw，19 秒 |
| 首次元信息解析 | 8520 ms |
| 字幕下载/内容校验 | 3206 ms；英文、人工、delivery=direct |
| 字幕 | VTT，440 字节，6 段 |
| 额外音频路径检查 | M4A，309288 字节，10568 ms |
| 诊断结果 | media_sample_verified=true，full_pipeline_verified=false，model_requests=0，退出码 0 |

音频检查单独调用生产下载函数，因此包含其自身平台解析；它不代表正常字幕命中后仍需下载音频。真实检查验证的是首选 M4A 路径，后备 WebM 路径由受控回归覆盖，不冒充本轮实际执行了 WebM/ASR。字幕时间是单样本，不与上一批不同网络/模型状态的总耗时计算提速比例。

此前单独的受控探测也确认固定样本的手动 VTT 直链返回 HTTP 200 / 440 字节；它不是浏览器或 HTTP 应用服务验收。
