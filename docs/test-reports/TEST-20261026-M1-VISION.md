| --- | --- | --- |

## 实际执行

- 定向回归最初两项断言失败：为验证模型层而设置的 1000ms 预算先触发了“低清下载余量不足 3 秒”的正确降级，模型没有启动。随后将模型测试预算改为 4000ms，并单独补上不足下载预算的用例；修正测试后通过。
- `npm run test:security`：239 项通过（203 TypeScript + 36 Python），失败 0、跳过 0；相较上轮新增 17 项。
- `npm run lint` / `npx tsc --noEmit`：均通过。
- 已按绝对路径同步独立副本并检查源码指纹；隔离 `npm run build`：通过，保留原有页面及 6 个 API 路由。仍有此前已存在的 Turbopack NFT 文件追踪范围警告（video-processor → 历史 transcribe 路由），不是本轮新增失败。
- `git diff --check`：通过。

本轮没有运行真实媒体或付费模型，没有启动 HTTP 服务/隧道、重启生产服务或构建根目录 .next。上述网络/进程证据来自可控替身，不能据此声称真实视觉质量或操作系统进程终止已实测通过。默认 30 秒的覆盖率与速度需真实样本补验。

HTTP/浏览器仍按用户此前要求暂缓、发布前补齐。此前被策略拒绝清理的忽略目录予以保留，本轮未再次尝试删除，也没有误建嵌套副本。后台索引、持久任务和完整进程树取消仍在后续计划。
