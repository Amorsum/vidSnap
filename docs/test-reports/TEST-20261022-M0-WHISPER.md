## 验证中修正

- 新客户端返回 language 可选，而历史接口类型要求字符串：历史接口缺省改为明确的 `unknown`，不假定识别语言；正常有语言的结果保持原值。
- 故障 fixture 初版使用 Node stdout.end/关闭 CRT fd，在本机 Windows 并未形成预期的管道 EOF，导致下一请求超时。换成真实 Python 关闭 stdout、进程保持存活的 fixture 后，EOF 收尾与后续重建通过；不把原 fixture 的行为当作产品 EOF 缺陷。
- 新测试的 prefer-const 和 killSignal 类型检查失败已修正，最终 lint/类型检查通过。
- 握手与默认模型统一使用 WHISPER_MODEL 或 medium，空配置也回退 medium；显式 tiny/其他模型仍保留。
- 单次脚本读取与结果解析后再次检查剩余期限，避免把到期结果当作成功；原队列计时器不会因失败被遗留。SSE 使用固定错误映射，模拟内部路径不出现在响应里。
