## 验证中发现和修正

- 删除发生在字幕下载期间时，底层失败会进入音频降级，并可能被误报为缺少 yt-dlp。现已在字幕重试/降级边界检查分析状态，删除统一提示分析已失效，后续结果不可回写；相应用例通过。
- 已存访问码原先先开放工作台再后台验证，会与首次会话签发形成竞态。现在等验证响应落 Cookie 后再开放提交，期间禁用重复验证；浏览器刷新及延迟响应检查通过。
- 测试驱动最初用整段含换行答案定位 DOM，与 Markdown 分段显示不匹配；改用实际可见回答片段后通过，接口当时已成功，不归类为产品功能失败。
- 隔离副本准备期间曾在依赖复制/构建未结束时启动检查，出现缺少 Next 模块/生产构建提示；待准备完成后构建和启动均通过。嵌套副本只在本地验证配置中限定 turbopack.root / outputFileTracingRoot，不修改项目正式 Next 配置。
- TypeScript 与 ESLint 增加 tmp 产物排除，避免隔离副本及生成物被当成项目源码重复检查；没有降低 src/tests 的检查规则。

## 剩余边界与资源收尾

- 没有真实 YouTube/抖音网络、云端/本地 ASR、多语言准确率、性能或付费模型评测。本批不能证明真实平台下载成功，也不提供提速或质量改善数字。

- DELETE 先撤销回写；当前外部阶段可能仍需等待结束，未宣称强杀或即时取消全部媒体/模型请求。资源目录在异常/删除后按本分析边界清理，到期扫描在启动后首次新分析触发，尚无独立清理进程。
