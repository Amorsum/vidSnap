# M1 第一批：文字链路基线与缓存前置

日期：2026-10-22。分支 demo，基于已推送的 `8d11f93`；本批已获用户确认，纳入本次提交。M0 的抖音/云端 ASR/部署层验收仍未补齐，M1 仅实施本批列出的计时与缓存改进。

## 用例与预期

| 用例 | 预期 |
| --- | --- |
| 计时与里程碑 | 单调时钟，首片段、总结解析完成与结果就绪独立；失败保留耗时；快照不能修改内部状态 |
| 未执行/降级 | 未执行阶段省略、里程碑 null；向量失败仍可总结并记录 degraded |
| 有效同会话缓存 | 规范 URL 直接复用完整证据，不调用平台、媒体或模型，不续期 |
| 其他会话/期限 | 他人缓存不复用，分析或缓存过期后重新解析/生成，旧记录不续期 |
| URL 分享变体 | 相同规范 ID 的分享参数/主机变体可命中同一授权缓存 |
| 真实文字路由 | 门禁、SSE 总结、追问、缓存、删除与删除后 404 均成功；真实上游，无媒体/模型替身 |
| 诊断边界 | 拒绝生产默认端口、远端地址或缺少 live 标记的 HTTP 服务；报告不含正文、签名 URL 或凭据 |
| 构建/资源 | 隔离构建；本次 Cookie 副本和临时目录清理，不影响原有生产服务 |

## 两次真实固定样本

通过 `scripts/check-pipeline-direct.ts` 调用生产 NextRequest 路由函数；没有监听 HTTP 端口，不经过浏览器。两次均使用固定公开视频 jNQXAC9IVRw，真实 yt-dlp、FFmpeg、DeepSeek 和 embedding 服务，关闭视觉；两次均命中内置字幕，因此没有实际调用云端 ASR 或 Whisper。每次只生成一次总结和一次追问，随后复用同一会话缓存并删除分析。

| 非缓存阶段（毫秒） | 计时接入、缓存前置前 | 缓存前置后 |
| --- | ---: | ---: |
| 元信息 | 9025 | 7292 |
| 下载（本例为字幕请求/转换） | 9017 | 5993 |
| 字幕文件解析 | 2 | 2 |
| 总结流与 JSON 解析 | 1989 | 1876 |
| embedding | 246 | 227 |
| 结果就绪 | 20288 | 15401 |
| 首个模型片段（从流水线起点） | 19017 | 13975 |
| 总结解析完成（从流水线起点） | 20042 | 15173 |

上述两次非缓存差异受平台/模型/本机缓存波动影响，本批没有对非缓存路径做并行提速，不能把 20.3→15.4 秒归因于缓存前置，也没有总体 p50/p95。

| 同会话缓存路径 | 前置前 | 前置后 |
| --- | ---: | ---: |
| 平台解析 | 5332 ms | 未执行 |
| 路由内部总耗时 | 5333 ms | 0 ms（整数取整精度以内，并非真实零延迟） |
| 模型流/首片段/总结解析里程碑 | 无/null/null | 无/null/null |
| 结果分析 ID / 总结 | 与首次一致 | 与首次一致 |

自动回归同时断言缓存命中前后媒体/模型/平台调用计数完全不增加，提速依据是移除了缓存路径的上游请求，而非只比较一次计时。

真实复验后还补充保留了解析后的缓存复查，并用受控并发测试确认等待期间其他请求完成时不会重复总结；同阶段累计实际查找耗时。该内存查找修正没有重复发起付费样本。

两次真实追问均返回非空回答，使用 semantic_search 和 segment_range，retrievalSource=rag。两次 DELETE 成功，随后追问返回 404。该检查验证协议、工具名和非空回答，不是多语言/幻觉率质量评测。没有归档付费请求的完整 usage，费用合计记为未知，不提供估算总额或宣称免费。

## 环境与限制

执行工具策略拒绝启动独立的 3419 端口验收服务，仅返回 `blocked by policy`，没有更具体原因。之后采用不监听端口的进程内路由验收；没有重试该被拒绝的服务启动。HTTP 实服、桌面/移动浏览器本轮未重新验证，不能把路由成功描述为浏览器端到端成功。

进程内验收把本次临时目录隔离到仓库 tmp 内，源项目 Cookie 只读复制到独立副本，由下载器使用副本；每次收尾删除副本 Cookie、本次临时目录并关闭本次 Whisper 客户端。生产根目录 .next 未覆盖，原有 3000/3001 服务不重启。诊断报告不保存字幕/总结/回答正文、Cookie、访问码、API Key、签名 URL、私有绝对路径或原始异常。
