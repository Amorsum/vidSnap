# M1 第三批：同会话在途请求合并

日期：2026-10-22。分支 demo，前两批已通过 `d37e846` 经代理推送。本批为后续开发，尚未提交/推送，需概述后经用户确认。

## 用例与结果

| 场景 | 预期 | 实际 |
| --- | --- | --- |
| 同会话规范 YouTube 链接变体并发 | 元信息和总结各执行一次，返回同一 analysisId | 通过，等待者 shared/cached 为 true，无重复模型流 |
| 不同会话同视频并发 | 独立解析、模型调用和分析 ID | 通过 |
| 等待者 abort / body cancel | 释放自身连接，不清理执行者或影响第三个等待者 | 两种路径均通过 |
| 执行者断连 | 继续完成，等待者收到结果，媒体按原策略清理 | 通过，总结仅一次 |
| 元信息/总结阶段失败 | 所有等待者收到安全错误，键释放，同会话可重试 | 两种路径均通过，元信息失败没有误建分析 |
| 共享分析删除并立即重试 | 等待者立即失败，旧执行不得回写、删除新键或影响新产物 | 通过 |
| 注册表/等待者容量 | 128 个执行键、每键 16 个等待者；满额拒绝，不重复执行 | 使用缩小容量的独立注册表测试通过 |
| 等待超时和已断连 signal | 移除订阅及名额，执行继续，重试加入同一执行 | 独立注册表测试通过 |
| 最新进度、不同抖音短码 | 仅最新进度带分析身份，无正文/流重放；不同短码独立 | 通过 |
| 共享计时与费用 | 等待计时独立、未执行阶段缺省、usage/cost 不复制 | 通过；诊断白名单保留 inflight_wait |

## 实际验证

- 定向 `tsx --test` 覆盖生产路由与注册表；所有媒体和模型上游在测试进程内被替换，没有启动 HTTP 监听。
- `npm run test:security`：222 项通过（186 TypeScript + 36 Python），失败 0、跳过 0。比前两批增加 15 项。
- `npm run lint`、`npx tsc --noEmit`：通过。
- 隔离副本 `npm run build`：重新同步并校验源码后通过，生成原有页面和 6 个 API 路由。保留此前已有的 Turbopack NFT 文件追踪范围警告（video-processor → 历史 transcribe 路由），不作为本轮新增失败；未构建根目录 .next。
- `git diff --check`：通过。

本轮没有真实模型/媒体小样本复测，既有真实结果见前两批报告。并发证据来自可控暂停的真实路由执行和替身上游，不用于推算生产吞吐量、成本节省百分比或 p95。

首次构建前的同步命令误将源码复制到隔离副本的 tmp 子目录，已纠正同步路径并校验路由哈希；首次构建不作为最终依据。清理误建目录被执行工具拒绝，仅返回 blocked by policy，未提供具体规则。该目录保留在已忽略的 tmp 中，没有加入提交；没有改用其他删除方式。原有隔离构建根目录及用户服务均未删除或重启。

HTTP/浏览器验收仍按用户要求暂缓，发布前补齐；本批不宣称 M0/M1 整体完成或具备持久任务恢复。
