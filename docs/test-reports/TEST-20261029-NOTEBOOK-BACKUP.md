# 笔记备份与恢复验证

日期：2026-10-29。范围：浏览器本地笔记的 JSON 备份与导入，不新增账号或服务器存储。

## 实现与预期

| 场景 | 预期 |
| --- | --- |
| 全库备份 | 保存总结、字幕、个人笔记、摘录、成功问答；不受标题筛选影响 |
| 敏感及临时字段 | 仅输出已知文字字段，去掉帧地址、图片地址和未知嵌套字段 |
| 导入预览/取消 | 展示文件名、篇数及前三个标题；确认前不写库 |
| 重复与冲突 | 相同内容跳过；同 ID 内容不同则另存副本，再次导入副本不膨胀 |
| 非法或过大文件 | 格式/版本/任意一篇不合法整份拒绝；上限 20 MiB / 500 篇 |
| 写入失败 | 单个读写事务回滚，不留下部分新笔记或覆盖原记录 |
| 现有编辑 | 原当前笔记与编辑内容保留，导入不切换当前笔记 |
| 其他浏览器 | 无需携带旧会话即可恢复文本，追问仍校验服务器会话及期限 |
| 三种宽度 | 1440 / 768 / 390，长文件名可换行，页面无横向溢出 |

## 服务恢复及限制

在一次隔离构建重试中，错误地从仓库根目录执行了 `npm run build`，影响了在线实例共享的 `.next`。完成该构建后核对原 3100 监听进程，只重启本仓库 Next 服务，保留既有 Cloudflare Tunnel；随后恢复隔离环境继续验收。

Chrome 访问本机 3100 和 `https://vidsnap.amorsum.top` 均为 200，确认“导入笔记备份”新入口与无运行时异常。线上目前包含本轮功能，但尚未提交或推送。服务重启使旧内存分析及追问资格失效，浏览器本地笔记不受影响；需追问时主动重新分析。公网验证仅覆盖页面加载，不代表再次执行了真实视频转写或模型流水线。

导入不包含图片、凭据或服务器持久任务，不提供自动同步。保持 IndexedDB / 笔记版本 1，不新增依赖。账号登录、跨设备同步和学习进度记录仍未实施。
