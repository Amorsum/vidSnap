日期：2026-10-29。上一批笔记备份已按授权由 `1f8d4be` 提交推送 `main` 并记录 plan-state；本报告覆盖随后继续开发的学习记录与生产重启。

## 功能与预期

| 场景 | 预期 |
| --- | --- |
| 旧 v1 笔记 | 缺少 learning 字段时为待学习 / 零复习，无需迁移 |
| 逐章勾选、取消及键盘操作 | 按当前总结章节计算待学习、学习中、已学完；无章节不误报完成 |
| 手动复习 | 每次点击计一次并记最近日期；普通阅读、刷新不自动计次 |
| 在线数据过期 | 本地学习记录仍可编辑，不延长追问资格 |
| 学习状态筛选 | 与标题搜索组合，空状态明确，不影响全库备份 |
| 保存失败 | 保留内存内容和原库，可恢复存储后重试 |
| 备份及 Markdown | 保留进度/复习信息；进度差异保留副本；坏索引整份拒绝 |
| 新分析与缓存 | 新分析从头记录，旧进度留旧笔记；有效缓存复用原进度 |
