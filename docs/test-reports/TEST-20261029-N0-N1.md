## N1 原型

- 本机启动临时 PostgreSQL 17 容器，使用 `--network none`，没有映射端口或载入真实凭据/数据；执行 [初版表结构](../../migrations/001_analysis_storage.sql) 成功。
- [SQL 契约检查](../../tests/n1-schema-contract.sql) 在事务内使用合成数据，验证 token 摘要长度/唯一性、归属外键、结果与证据原子完整性、期限约束、帧清单类型、删除后不保留结果，以及带状态条件的旧写入无法复活已删除分析；测试数据回滚。
- 另启 PostgreSQL 17 临时容器，仅绑定本机随机端口，使用合成数据测试 [存储适配器](../../src/lib/persistence/postgres.ts)：会话摘要及期限、归属、条件写入、对话窗口、删除竞争、失败回滚和脱敏错误均通过。另一个 Node 进程能够读取测试数据；这不等于网站重启恢复验收。
- 增加显式迁移命令 `npm run migrate:persistence`（使用 `VIDSNAP_DATABASE_URL`），在事务和数据库锁中应用固定迁移，并记录 SHA-256；并发执行、重复执行与迁移文件不一致拒绝已在隔离库验证。不会在应用启动时自动执行。
- 帧清单仅允许保存帧编号、时间和描述，拒绝签名链接、重复编号及越界编号；删除时清除清单并记录待清理标记，测试确认该标记跨存储实例保留，成功确认后才移除。清理任务尚未接入应用。
- `npm run test:persistence` 需要隔离本机数据库 `vidsnap_n1_test`，并显式设置 `VIDSNAP_TEST_DATABASE_URL` 和 `VIDSNAP_TEST_DATABASE_CONFIRMED=1`；测试自动执行迁移，未设置时跳过。测试只允许 `127.0.0.1` 和该数据库名。不得指向真实数据。
- 本轮 lint、TypeScript、267 项 TypeScript 和 49 项 Python 安全回归通过；数据库适配器实际连接隔离库的测试通过。新增 `pg` 后 npm audit 与原锁文件基线均报告 10 项问题（其中 Next.js 一项为 critical）；尚未评估具体影响，也未自动升级依赖。
- 表约束和适配器不能单独保证应用安全。完整结果及证据的应用边界校验、网站会话和路由接入、故障响应、帧签名、清理任务接入及真实应用重启和越权集成测试仍待完成。
- 原型未配置生产数据库，也未改变现有内存实现。临时测试容器在检查结束后停止；镜像保留以供后续隔离测试。
