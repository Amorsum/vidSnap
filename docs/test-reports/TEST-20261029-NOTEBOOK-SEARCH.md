日期：2026-10-29。用户要求先提交推送再继续完善：上一批学习进度与复习记录已由 `454aec0` 推送 `main`，README、截图和进展日志同步，使用实际 `.claude/hooks/plan-state.sh record` 记录指纹。本报告覆盖接续的本地搜索。

## 预期与行为

| 场景 | 预期 |
| --- | --- |
| 内容范围 | 标题、个人笔记、摘录、成功问题/回答、总结、字幕均可命中 |
| 片段来源 | 展示原始文字和匹配高亮，不跨字段拼接，不解释 HTML |
| 定位 | 时间命中打开原文；个人笔记选中文字；问答定位对应条目 |
| 旧全文 | 无分段时仍能搜索与阅读，不伪造时间 |
| 查询规则 | 忽略大小写，字面短语匹配，最多 200 字符、每篇三处来源命中 |
| 组合筛选 | 与学习状态同时生效；显示笔记篇数，不影响全库备份 |
| 数据变更 | 编辑立即参与搜索，删除后命中失效；不写搜索索引或新数据库结构 |
| 服务不可用 | 服务器在线资格不可确认时仍可搜索本地内容，不调用付费流水线 |

## 界面与限制

沿用 `design-taste-frontend` 先前的 Achromatic ledger 方向（seed `1464537962`），保持现有品牌、字体和工作台外框；仅补充查询、结果数量、来源片段与高亮，不新增图表或装饰指标。核心问题是“先前学过的知识在哪篇笔记、什么位置”。

真实浏览器 inspector 在三宽度下，沿用已有页面例外 `gradient,button-fx,heavy-shadow,icon-chips,tiny-text,app-title-size` 后无新增规则发现。该自动检查覆盖空工作台；有内容的结果滚动区、定位和长文本由上述交互及截图核对，不能据此宣称全站已符合默认视觉规则。记录 `tmp/search-taste/inspect/`。

每个来源只展示第一处匹配，每篇最多三处；不做分词、模糊搜索、拼音、语义搜索或跨字段组合。查询不持久化，刷新后需重新输入；搜索的计算只在浏览器内完成，未测量大量真实笔记下的 p95 延迟。结果打开仍会用分析 ID 检查在线资格，不发送搜索词或笔记正文。
