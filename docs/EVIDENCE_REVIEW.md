# 人工事实依据核查

此工具协助人工比较总结与字幕、画面描述，不调用模型或数据库，不判断转写本身是否准确。可使用单份分析 JSON 或网站导出的笔记备份，所有检查在本机执行。

```powershell
npm run review:evidence -- prepare "D:\备份\notes.json" "D:\备份\review.json"
# 在编辑器中检查 review.json，为每条结论填写 review 后：
npm run review:evidence -- report "D:\备份\notes.json" "D:\备份\review.json"
```

`prepare` 不覆盖已存在的文件。核查表**包含字幕、画面描述和总结文字**，应当像原备份一样保护，不要直接提交仓库或公开分享。工具不写入帧链接、Cookie 或个人笔记。`report` 只输出统计与输入内容指纹，不输出正文。

表中 `sources` 给出证据 ID：`t` 开头代表字幕段，`f` 代表画面描述；`claims` 包括整体总结和每个要点。`candidates` 是同一时间附近的线索，不代表支持结论；应阅读相关上下文并自行挑选其他证据。核对否定词、数字、单位、人物、条件和时间，特别注意估算字幕时间。

只修改每个 `review`：

- `verdict`：`unreviewed`（未核查）、`supported`（有依据）、`contradicted`（与依据矛盾）、`insufficient`（依据不足）。
- `evidenceIds`：填写相关证据 ID。前两种已核查结论必须至少提供一个非空证据；依据不足可留空。
- `reason`：已核查项填写判断理由；未核查项保持空字符串和空证据列表。

报告区分四种数量，支持率以**已核查项**为分母；没有已核查项时为 `null`。未完成或存在矛盾、依据不足时退出码为 1；全部填写为有依据时退出码为 0；格式错误或输入与核查表不匹配时为 2。这只是人工填报状态，不能证明评判本身正确，也不能概括真实视频质量。

工具会比较输入指纹、证据和全部要点，防止改掉输入或删除困难要点后继续使用旧表；更改输入后应重新生成。不要编辑证据、要点或候选索引。人工作出相互矛盾或错误的判定仍需复核，此工具不能自动识别。
